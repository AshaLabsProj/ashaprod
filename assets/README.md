# Assets

Placeholder location for app icons and splash referenced by `app.json`:

- `icon.png`           1024×1024  app icon
- `adaptive-icon.png`  1024×1024  Android adaptive icon foreground
- `splash.png`         ~1284×2778 splash image

Drop real PNGs here before running `eas build`. Until then, run
`npx expo install expo-splash-screen` defaults or generate placeholders with
`npx @expo/configure-splash-screen`. The app boots without them in Expo Go.
